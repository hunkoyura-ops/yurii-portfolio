Four tools for the routine parts of influencer marketing.

Writing scripts, retyping stats from screenshots, sorting replies, scrolling for creators. I built a tool for each. Every one of them leaves the final call to a person. Try them below on sample data.

Brief Script

Live

Turns a brand brief and a creator's tone into a timecoded script draft: hook, body, proof and call to action, with on-screen text, a caption and hashtags.

Modes
One creator, a whole batch in one pass, or saved presets for creators you work with often
Export
Google Docs or a .doc file
Safety net
Falls back to local templates when the AI is unavailable, so it never returns nothing
Built with
Cloudflare Workers, Claude API

Post Report

Live, team access

Reads the stats from a creator's screenshot and builds the campaign report for the brand. Anything that can't be true is held back for a person to check, with the reason attached.

Reads
Views, reach, likes, comments, shares, saves
Two views
By campaign, with totals and a written summary. By creator, across every campaign they did
Checks
Likes above views, engagement over 100%, reach far beyond the follower count
Built with
Node.js, Claude Vision, Railway. Creator profiles are plain arithmetic, no AI call

Inbox Triage

Live in n8n

After outreach the replies pile up and the good ones get lost. This sorts each one by what the creator wants, pulls out the specifics and leaves a draft answer in Gmail. Nothing is sent without me.

Sorts into
Interested, negotiating, question, declined, spam
Pulls out
Quoted prices, deadlines, open questions
Guardrails
The model may not invent budgets or dates. A malformed answer gets logged, the flow keeps running
Built with
n8n, Claude API, Gmail, Google Sheets
